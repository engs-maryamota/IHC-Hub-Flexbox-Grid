Flexbox (abreviação de Flexible Box) é um modelo de layout unidimensional do CSS que facilita a distribuição, o alinhamento e o redimensionamento de elementos dentro de um contêiner, mesmo quando seus tamanhos são desconhecidos ou dinâmicos.

𝓞𝓼 𝓿𝓪𝓵𝓸𝓻𝓮𝓼 𝓹𝓻𝓲𝓷𝓬𝓲𝓹𝓪𝓲𝓼 𝓼𝓪̃𝓸:

  • ˚˖𓍢ִ໋❀ flex-direction — define a direção do flex container;
  • ˚˖𓍢ִ໋❀ flex-wrap — define se os itens devem quebrar para a próxima linha;
  • ˚˖𓍢ִ໋❀ flex-grow — define quanto um item deve crescer em relação aos outros;
  • ˚˖𓍢ִ໋❀ flex-shrink — define quanto um item deve encolher em relação aos outros;
  • ˚˖𓍢ִ໋❀ flex-basis — define o tamanho inicial de um item antes do redimensionamento.
