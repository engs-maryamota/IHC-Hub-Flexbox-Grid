O CSS Grid Layout é um sistema de layout bidimensional que permite criar layouts complexos e responsivos de forma mais simples e eficiente. Ele organiza os elementos em linhas e colunas, facilitando o posicionamento e o dimensionamento dos itens dentro de um contêiner.

𝓞𝓼 𝓿𝓪𝓵𝓸𝓻𝓮𝓼 𝓹𝓻𝓲𝓷𝓬𝓲𝓹𝓪𝓲𝓼 𝓼𝓪̃𝓸:

  • ˚˖𓍢ִ໋❀ grid-template-columns — define o número e o tamanho das colunas;
  • ˚˖𓍢ִ໋❀ grid-template-rows — define o número e o tamanho das linhas;
  • ˚˖𓍢ִ໋❀ grid-gap — define o espaçamento entre as linhas e colunas;
  • ˚˖𓍢ִ໋❀ grid-area — define a área ocupada por um item no grid;
  • ˚˖𓍢ִ໋❀ justify-items — alinha os itens horizontalmente dentro de suas células;
  • ˚˖𓍢ִ໋❀ align-items — alinha os itens verticalmente dentro de suas células.
